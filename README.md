## About

I run **ZENTRA Creates**, a small studio for websites, brand visuals and business automation. Most of my work is end-to-end: design direction, front-end, back-end, data and deployment.

- Comfortable across the stack — React and Next.js front ends, Node.js and SQLite back ends, static sites on Cloudflare Pages, apps on Cloudflare Workers.
- I build for real use: working admin panels, stock and order flows, printable documents, offline reading, WhatsApp ordering.
- Security-minded by default: hashed passwords, CSRF tokens, role checks, environment-based secrets, no keys in source.
- Also interested in Windows systems and diagnostics — process, token and integrity-level inspection with PowerShell and Python.
